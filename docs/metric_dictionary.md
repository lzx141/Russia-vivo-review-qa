# 指标字典

所有指标都必须同时呈现分母或有效样本量。不同指标使用不同准入标记，不能因为一条记录缺日期就从所有分析中整行删除。

| 指标 | 口径 | 分母/准入 |
|---|---|---|
| 总记录数 | 当前分组全部规范化记录数 | `total_records` |
| 文本有效记录数 | `is_text_eligible=true` 的记录数 | 当前分组全部记录 |
| 文本质量通过率 | 文本有效记录数 / 总记录数 | 当前分组全部记录 |
| 平均质量分 | 非空 `quality_score` 均值 | 有质量分的记录 |
| 平均评分 | 有效 `rating` 均值 | `is_rating_eligible=true` |
| 负面率 | 评分 ≤2 的评论占比 | `is_rating_eligible=true` |
| 月度记录数 | 按 `event_date` 月份汇总 | `is_trend_eligible=true` |
| 商品反馈量 | 按稳定 `product_id` 汇总 | `is_product_eligible=true`，同时保留该商品总记录数 |
| 重复率 | 指纹重复隔离数 / 输入数 | 当前运行 manifest 的输入记录 |
| 质量门禁通过率 | DWD 接受数 / 输入数 | 当前 `pipeline_run_id` |
| 文本缺失率 | 空文本数 / 匹配样本数 | 来源对照的平衡 cohort |
| 文本长度差 | 两来源平均/中位文本长度差 | 共同 `product_id` 的等量样本；报告 Bootstrap 95% CI 与 Mann-Whitney U |
| 评分分布差异 | 1–5 星分布比较 | 两来源均存在有效评分时；报告卡方检验与 Jensen-Shannon 散度 |

来源对照的限制：它是对同商品、等量抽样后的观察性比较。平台机制、记录类型和采集时期仍可能混杂结果，因此报告会显式输出 `limitations`，禁止将其描述成随机 A/B 实验。

管道离线基准只比较保留数、隔离数、重复识别、指标准入和运行耗时。没有独立人工标注时，不报告“准确率提升”。

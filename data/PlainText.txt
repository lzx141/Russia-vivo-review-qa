
##  快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置数据库

项目使用环境变量来管理敏感信息，MySQL 密码通过环境变量 `MYSQL_PASSWORD` 设置：

**Windows (命令提示符)**：
```bash
set MYSQL_PASSWORD=你的MySQL密码
```

**Windows (PowerShell)**：
```powershell
$env:MYSQL_PASSWORD="你的MySQL密码"
```

**Linux/Mac**：
```bash
export MYSQL_PASSWORD=你的MySQL密码
```

`config.py` 文件已配置为从环境变量读取密码：
```python
DB_CONFIG = {
    'host': 'localhost',
    'port': 3306,
    'user': 'root',
    'password': os.getenv('MYSQL_PASSWORD', ''),  # 从环境变量读取
    'database': 'russia_ecommerce'
}
```

### 3. 初始化数据库

```bash
python init_database.py
```

### 4. 执行 ETL

```bash
python etl.py
```

##  数据库结构

### reviews 表（评论数据）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| author | VARCHAR(255) | 评论作者 |
| publish_date | DATETIME | 发布日期 |
| rate | INT | 评分 |
| content | TEXT | 评论内容 |
| name | VARCHAR(255) | 商品名称 |
| sku | VARCHAR(255) | 商品 SKU |
| url | TEXT | 商品链接 |
| site_name | VARCHAR(50) | 平台名称 |

### questions 表（问答数据）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| author | VARCHAR(255) | 提问者 |
| publish_date | DATETIME | 提问日期 |
| question | TEXT | 问题内容 |
| content | TEXT | 回答内容 |
| name | VARCHAR(255) | 商品名称 |
| sku | VARCHAR(255) | 商品 SKU |
| url | TEXT | 商品链接 |
| site_name | VARCHAR(50) | 平台名称 |
